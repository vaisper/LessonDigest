# 00 — Overview: что это за продукт

## 1. Проблема

На уроке школьник часто:
- не успевает записать;
- болел / отсутствовал;
- забыл, что задали на дом;
- имеет сырую диктофонную запись, которую неудобно переслушивать (45 минут).

Учителю и родителю тоже полезен краткий итог: что реально было пройдено и что задано.

## 2. Решение

**LessonDigest** — система, которая принимает **аудиозапись урока** и возвращает **структурированный дайджест**:

1. Тема урока  
2. Ключевые понятия и определения  
3. Главные тезисы  
4. Формулы / правила (если есть)  
5. Домашнее задание (цитата из речи, если упоминалось)  
6. Вопросы, которые стоит уточнить  

## 3. Главный тезис (product thesis)

```text
запись урока  →  дайджест (главное + домашка)
```

Всё остальное (Telegram, своя математика, PWA, офлайн) — надстройки над этим тезисом.

## 4. Целевая аудитория

| Кто | Зачем |
|-----|--------|
| Ученик 9–11 класса | Конспект, если не успел / болел |
| Одноклассники | Общий бот / общий доступ к дайджестам |
| Учитель (опционально) | Проверка, что было сказано; шаблоны |
| Родитель (опционально) | Понять домашку |

Первичный пользователь MVP0: **сам автор проекта + 3–10 одноклассников**.

## 5. Что НЕ входит в продукт (non-goals)

На этапе MVP0 и даже MVP1 **не делаем**:

- собственную ASR-модель «с нуля»;
- нативное iOS/Android приложение как обязательный deliverable;
- автоматическую оценку знаний ученика;
- подмену учителя / «решить контрольную вместо тебя»;
- скрытую запись без согласия;
- гарантию 100% точной домашки в шумном классе.

## 6. Тип проекта (школьный контекст)

- Класс: ~10, инженерный профиль  
- Навыки: интересно **программирование**, нет инженерной пайки  
- Требование: **практическая польза** + возможность защиты  
- Ограничение среды: сервисы **доступны из РФ без VPN**, оплата картой РФ при необходимости  

## 7. Критерии «живучего» продукта

Проект считается удачным, если после защиты:

1. Автор сам пользуется им хотя бы раз в неделю.  
2. Есть ≥ N внешних пользователей (одноклассники) без постоянной ручной помощи автора.  
3. Есть измеримые метрики (см. `07_METRICS.md`).  
4. Есть понятный путь развития на год (см. `09_ROADMAP.md`).

## 8. Формулировка темы для защиты (черновик)

> «Программная система автоматической транскрипции и структурированной суммаризации школьного урока на основе ASR и большой языковой модели».

**Гипотеза MVP0:**  
аудиозапись урока (10–20 мин) можно автоматически преобразовать в структурированный дайджест (ASR + LLM) с качеством, достаточным для практического использования (средняя оценка полезности ≥ 3.5 из 5; домашка корректна в ≥ 70% случаев).
