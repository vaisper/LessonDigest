# 12 — Defense: защита школьного проекта

## 1. Формулировки

**Тема:** Программная система автоматической транскрипции и структурированной суммаризации школьного урока.

**Цель:** разработать и экспериментально проверить пайплайн «аудио → текст → дайджест», пригодный для практического использования учеником.

**Гипотеза:** связка ASR + LLM даёт дайджест с средней полезностью ≥ 3.5/5 и корректным выделением домашнего задания ≥ 70% на тестовом наборе.

## 2. Что показать комиссии (минимум)

1. Архитектурная схема пайплайна.  
2. Обоснование выбора GigaChat + Whisper (доступ из РФ, без VPN).  
3. Live или записанное демо.  
4. Пример входа (фрагмент транскрипта) и выхода (дайджест).  
5. Таблица метрик.  
6. Ограничения: шум, согласие, галлюцинации LLM.  
7. План развития (своя математика / бот).

## 3. Типовые вопросы и ответы

**«Это же просто ChatGPT?»**  
— Нет: спроектирован пайплайн, адаптеры, версии промптов, метрики, хранение артефактов; LLM — один модуль. Дальше — сравнение с собственными алгоритмами выделения ключевого.

**«Где математика?»**  
— MVP0: постановка эксперимента, метрики, статистика оценок. Version 2: TF-IDF, TextRank, кластеризация, сравнение с LLM.

**«Почему не мобильное приложение?»**  
— Инженерный подход: сначала проверить ценность (MVP), потом UX. Мобильная разработка — отдельный риск по срокам.

**«А персональные данные?»**  
— Согласие учителя, режим hybrid, политика хранения, whitelist бота.

## 4. Структура отчёта (оглавление)

1. Введение (проблема, актуальность)  
2. Цель и задачи  
3. Обзор аналогов (диктофон, Notes, облачные ASR)  
4. Архитектура  
5. Методы (ASR, LLM, промпт)  
6. Реализация  
7. Эксперимент и результаты  
8. Обсуждение ограничений  
9. Заключение и развитие  
10. Приложения (промпт, примеры, таблицы)

## 5. Критерии оценки «для себя»

| Критерий | Как закрываем |
|----------|----------------|
| Практическая польза | Реальные пользователи / самоиспользование |
| Инженерия | Архитектура, модули, воспроизводимость |
| Исследование | Метрики, честные fail-кейсы |
| Математика | План Version 2 + базовый анализ сейчас |
| Презентация | Схема + демо + цифры |
