# 16 — Оценки полезности и домашнего задания

Человеческая оценка дайджестов по методике `docs/07_METRICS.md`. Артефакт-сводка
формируется командой `lessondigest eval` в `digests/_eval/summary.md`
(папка не попадает в git), здесь — зафиксированный результат.

## 1. Метод

Для каждого прогона оценивается:

- **полезность 1–5** — «насколько конспект помог бы вспомнить урок / подготовиться»;
- **домашка**: `yes` / `no` / `na` — совпадают ли номера и задание с транскриптом.

Команда:

```powershell
lessondigest eval --run <run_id> --usefulness <1-5> --homework <yes|no|na> --evaluator author
```

## 4. Ограничения

- Оценки даны автором проекта на **синтетических** уроках (TTS), а не на полевых
  записях с шумом — оценка полезности может быть завышена (риск R1).
- n = 3; для статистической значимости нужен набор из 5–10 разных уроков.
- Разные версии промпта: физика — `v1.1`, алгебра и история — `v1`.
