# 06 — Security & Privacy

## 1. Почему это критично

Аудио урока может содержать:
- голоса учеников и учителя;
- персональные обращения;
- оценки, дисциплинарные замечания.

Это **персональные данные / чувствительный контент**. Школьный проект без правил приватности может быть остановлен администрацией.

## 2. Обязательные правила продукта

1. **Явное согласие учителя** перед записью реального урока.  
2. Сообщать, **куда уходят данные** (локально / GigaChat / SpeechKit).  
3. Не публиковать сырые аудио и полные транскрипты без анонимизации.  
4. Секреты API только в `.env`, `.env` в `.gitignore`.  
5. Не коммитить `audio/`, `transcripts/` с реальными уроками в публичный git (если появится remote).

## 3. Режимы обработки данных

| Режим | Аудио | Текст | Риск | Когда |
|-------|-------|-------|------|-------|
| Hybrid MVP0 | локально (Whisper) | в GigaChat | средний | старт |
| Cloud ASR+LLM | оба в облаке | оба | выше | только с согласием |
| Full local | локально | локально | ниже | цель «приватность» |

В отчёте для защиты **обязательно** указать выбранный режим.

## 4. Минимизация данных

- Не хранить записи дольше, чем нужно для эксперимента (политика retention: например 30 дней).  
- Для демонстрации на защите — **синтетические / открытые лекции** или короткие фрагменты с согласием.  
- В дайджесте промптом запретить выдумывать ФИО и оценки.

## 5. Согласие (чеклист)

Перед полевыми тестами:
- [ ] Учитель согласен на запись  
- [ ] Понятно, что делается с аудио  
- [ ] Есть возможность удалить запись по запросу  
- [ ] Родители/администрация — по правилам школы (уточнить!)

Шаблон короткого согласия — можно добавить в `docs/legal/consent_template.md` позже.

## 6. Безопасность секретов и API

- OAuth GigaChat: токен короткоживущий → refresh в адаптере.  
- Не логировать полные промпты с ПДн на чужие сервисы.  
- Rate limit / retry без утечки текста в issue trackers.  
- TLS GigaChat проверяется по сертификатам российского УЦ
  (`certs/russian_trusted_ca_bundle.pem`); `verify_ssl: false` использовать не рекомендуется.

## 7. Веб-интерфейс (MVP1, реализован)

- Авторизации нет: слушать только `127.0.0.1` либо свою Wi-Fi-сеть.  
- Наружу в интернет выставлять нельзя без логина и HTTPS (план).  
- По Wi-Fi данные идут по локальной сети в открытом виде — учитывать при полевых тестах.  
- Принятые загрузки лежат в `audio/incoming/` и удаляются после обработки.
