# 08 — MVP0: подробный scope

## 1. Цель MVP0

**Доказать гипотезу:** запись урока → полезный дайджест через ASR + LLM.  
Не сделать магазинный продукт. Не сделать мобильное приложение.

Срок: **2–4 недели** активной работы.

## 2. In scope

- [ ] Репозиторий/папка на `D:\LessonDigest` с архитектурой (этот пакет docs)  
- [ ] Python CLI: `run --audio ...`  
- [ ] Ingest + meta  
- [ ] ASR: faster-whisper, ru  
- [ ] Summarize: GigaChat + prompt v1  
- [ ] Выход: `.md` + `.json`  
- [ ] Логи таймингов  
- [ ] 5–10 тестовых прогонов + оценки  
- [ ] Короткий отчёт эксперимента  

## 3. Out of scope (явно)

- Telegram-бот  
- PWA / Flutter  
- Своя ASR  
- TF-IDF / TextRank (это Version 1)  
- Авторегистрация пользователей  
- Красивый UI  
- Поддержка iOS background recording app  

## 4. Definition of Done

1. На новой записи команда отрабатывает end-to-end без ручного копипаста в ChatGPT.  
2. Дайджест содержит обязательные секции.  
3. Есть сохранённые артефакты audio→transcript→digest для демо.  
4. Есть таблица оценок.  
5. Риски/ограничения записаны.

## 5. План по неделям

### Неделя 1 — ASR
- Установка Python, ffmpeg, faster-whisper  
- Скрипт `audio → txt`  
- 2 тестовых файла  

### Неделя 2 — LLM
- Регистрация GigaChat  
- Адаптер + prompt v1  
- `txt → md/json`  
- Подбор модели (Lite vs Pro)  

### Неделя 3 — Склейка CLI
- Единый `run`  
- run_id, папки, meta  
- Обработка ошибок  
- Chunking если упрётесь в лимит  

### Неделя 4 — Эксперимент
- 5–10 записей  
- Оценки  
- Правки промпта → v1.1 (зафиксировать)  
- Материалы к промежуточному отчёту  

## 6. Демо-сценарий на защите (черновик)

1. Показать 30–60 сек фрагмент записи (или сказать «полный урок 15 мин»).  
2. Запустить CLI (или показать заранее полученные артефакты + один live short).  
3. Открыть дайджест: тема / тезисы / домашка.  
4. Показать таблицу метрик.  
5. Честно: ограничения шума и согласие.

## 7. Бюджет

- GigaChat freemium — целевой zero-cost.  
- Электричество/время ноутбука.  
- Не планировать платный OpenAI.
