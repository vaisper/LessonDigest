# 11 — Prompts: промпты LLM

## 1. Принципы

1. Промпт — **часть продукта**, версия обязательна (`prompt_version`).  
2. Требовать опору на транскрипт: не выдумывать домашку и формулы.  
3. Предпочтительно просить **JSON**, markdown рендерить самим.  
4. Для школы: простой язык, без «воды».

## 2. System / роль

```text
Ты — помощник школьника. Твоя задача — сделать честный структурированный
конспект по транскрипту урока. Не выдумывай факты, которых нет в тексте.
Если домашнее задание не упоминалось — явно укажи это.
Формулы переписывай только если они звучат/описаны в тексте.
```

## 3. Prompt v1 (user)

Файл: `prompts/v1_digest.txt`

```text
Ниже — транскрипт школьного урока (может содержать ошибки распознавания речи).

Сделай структурированный конспект и верни СТРОГО JSON (без markdown вокруг) вида:
{
  "topic": "строка — тема урока",
  "concepts": ["понятие — краткое определение", "..."],
  "key_points": ["тезис 1", "тезис 2", "... 5-7 пунктов"],
  "formulas": ["формула или правило", "..."],
  "homework": "цитата/пересказ домашки или null",
  "homework_confidence": "high|medium|low|absent",
  "questions": ["что стоит уточнить у учителя", "..."]
}

Правила:
- Пиши по-русски.
- key_points — самое важное для подготовки к следующему уроку/контрольной.
- homework_confidence=absent и homework=null, если домашка не звучала.
- Не добавляй темы, которых не было в транскрипте.
- Если транскрипт шумный/обрывочный — отрази это в questions.

Транскрипт:
"""
{{TRANSCRIPT}}
"""
```

### 3.1. Prompt v1.1 (актуальный)

Файл: `prompts/v1_1_digest.txt`. Отличия от v1 — только правила формата:

- формулы обычным текстом, **без LaTeX** (`$`, `\frac`, `\cdot`, `\times`, `^{}`, `_{}`);
- умножение `·`, деление `/`, степень `²` / `³`;
- общеизвестные величины — строчными латинскими (`m`, `a`, `F`, `g`, `D`);
  латинские буквы, распознанные ASR как русские/заглавные (`М`, `Е`), приводятся
  к стандартному виду (например, «F равно M умножить на E» → `F = m · a`);
- внутри JSON-строк — без Markdown (звёздочки, обратные кавычки, списки).

Дополнительно в коде есть нормализатор `summarize/normalize.py` — страховка,
если модель всё-таки вернёт LaTeX: убирает `$`, `\frac{a}{b}` → `a / b`,
`^{2}` → `²`, `_{1,2}` → `₁,₂`, `\cdot` → `·`, `−` → `-`. Версия промпта
пишется в `run.json`, поэтому прогоны на v1 и v1_1 не смешиваются.

## 4. Рендер Markdown (шаблон приложения)

```markdown
# {topic}

## Ключевые понятия
- ...

## Главные тезисы
1. ...

## Формулы и правила
- ...

## Домашнее задание
{homework | «В транскрипте не обнаружено»}

## Вопросы для уточнения
- ...

---
_Сгенерировано LessonDigest · prompt {prompt_version} · model {model}_
```

## 5. Map-промпт (для чанков)

Кратко резюмировать чанк тем же JSON, поле `topic` может быть null.  
Reduce-промпт: слить JSON чанков; при конфликте домашек предпочесть **последний** чанк урока (обычно домашку дают в конце).

## 6. Антипаттерны

- «Напиши красивый конспект» без структуры.  
- Разрешить модели «додумать» материал учебника.  
- Один промпт на всё + ещё и «оцени ученика».
