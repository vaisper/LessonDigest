# 09 — Roadmap: эволюция после MVP0

## Версия 0 — MVP0 (доказательство цепочки)
См. `08_MVP0.md`.  
Артефакт: CLI + эксперимент.

## Версия 1 — Продуктовый UX (Telegram)

**Цель:** одноклассник кидает файл в бота и получает дайджест.

Состав:
- Telegram bot + whitelist  
- Тот же pipeline  
- Очередь из одного worker  
- История run_id в SQLite  

Метрика: N активных пользователей за 2 недели.

## Версия 1.5 — Качество контента

- Улучшение промптов под предметы (математика / история разные шаблоны)  
- Эвристики поиска домашки (regex + LLM)  
- Сравнение GigaChat vs YandexGPT  

## Версия 2 — Своя математика (научная часть)

Параллельный контур:

```text
transcript → TF-IDF / TextRank / clustering → candidate key points
                │
                ▼
         сравнение с LLM digest
```

Это отвечает на риск «это просто обёртка над нейросетью»: есть **свой алгоритм** и сравнение.

Метрики: overlap key points, homework detection F1, экспертная оценка.

## Версия 3 — Удобство записи

- PWA с MediaRecorder в браузере телефона  
- Или инструкция «диктофон → бот» доведена до 3 тапов  

Нативное приложение — только если V0–V2 стабильны и есть время.

## Версия 4 — Приватность full-local

- Локальная LLM (GGUF)  
- Рекламный тезис: «аудио не покидает устройство/ноутбук»  
- Сравнение качества local vs GigaChat  

## Версия 5 — Школьное внедрение (опционально)

- Привязка к расписанию  
- Папки по предметам  
- Роль учителя (только свои классы)  
- Политика хранения согласована с школой  

## Что сознательно откладываем навсегда (возможно)

- Распознавание формул с доски по видео  
- Real-time субтитры на уроке  
- Автоматическая генерация ДЗ «от себя»
