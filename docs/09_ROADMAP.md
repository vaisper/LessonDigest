# 09 — Roadmap: эволюция после MVP0

## Версия 0 — MVP0 (доказательство цепочки)
См. `08_MVP0.md`.  
Артефакт: CLI + эксперимент.

## Версия 1 — Продуктовый UX (веб-интерфейс)

**Цель:** загрузить запись урока через браузер и получить дайджест.

Состав (сделано, см. ADR-0007; Telegram-бот отменён):
- FastAPI + Uvicorn, страница загрузки и просмотра дайджеста
- Фоновая очередь с одним worker-потоком
- Запуск: `lessondigest serve`; доступ с телефона по Wi-Fi
- История run_id читается из `runs/` (SQLite — опционально позже)

Метрика: N активных пользователей за 2 недели.

## Версия 1.5 — Качество контента

- Улучшение промптов под предметы (математика / история разные шаблоны)  
- Эвристики поиска домашки (regex + LLM)  
- Сравнение GigaChat vs YandexGPT  

## Версия 2 — Своя математика (научная часть)

**Сделано** (см. `docs/14_ANALYTIC.md`, ADR-0008):

```text
transcript → TF-IDF (ключевые термины) + TextRank (ключевые предложения)
           + regex-детектор домашки
                 │
                 ▼
         сравнение с LLM digest (precision/recall/F1, grounded_ratio)
```

Отвечает на риск «это просто обёртка над нейросетью»: есть **свой алгоритм** и сравнение.
Результаты — в `docs/15_ANALYTIC_RESULTS.md`.

## Версия 3 — Удобство записи

- PWA с MediaRecorder в браузере телефона (загрузка файла уже сделана, осталась запись)  
- Или инструкция «диктофон → веб» доведена до 3 тапов  

Нативное приложение — только если V0–V2 стабильны и есть время.

## Версия 4 — Приватность full-local

- Локальная LLM (GGUF)  
- Рекламный тезис: «аудио не покидает устройство/ноутбук»  
- Сравнение качества local vs GigaChat  

## Версия 5 — Школьное внедрение (опционально)

- Привязка к расписанию  
- Папки по предметам  
- Роль учителя (только свои классы)
