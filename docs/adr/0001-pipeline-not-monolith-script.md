# ADR-0001: Пайплайн вместо монолитного скрипта

- Status: Accepted
- Date: 2026-09-22

## Context

Легко написать один `main.py` на 300 строк: прочитал файл → whisper → httpx → print.  
Это быстро ломается при смене LLM, добавлении бота и повторных прогонах.

## Decision

Разбить систему на стадии и адаптеры (ingest / asr / summarize / deliver) с артефактами на диске между стадиями.

## Consequences

+ Можно перезапускать с `--from summarize`  
+ Легко заменить GigaChat на YandexGPT  
+ Прозрачно для защиты  
− Чуть больше кода и папок на старте
