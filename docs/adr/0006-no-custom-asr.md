# ADR-0006: Не разрабатываем собственную ASR

- Status: Accepted
- Date: 2026-09-22

## Context

Соблазн «обучить свою модель распознавания речи» для инженерного класса.

## Decision

Запрещено в scope проекта: обучение ASR с нуля.  
Используем готовые движки; ценность — пайплайн, суммаризация, метрики, позже свои NLP-алгоритмы поверх текста.

## Consequences

+ Реалистичные сроки  
+ Честная инженерия  
− Нельзя заявлять «я создал распознавание речи»
