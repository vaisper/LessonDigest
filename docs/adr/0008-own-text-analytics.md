# ADR-0008: Своя текстовая аналитика (TF-IDF + TextRank)

- Status: Accepted
- Date: 2026-09-28

## Context

Вся «умная» обработка текста выполнялась внешней LLM (GigaChat). Для школьного
инженерного проекта это риск: работу могут оценить как «обёртку над чужим API»,
без собственного вклада и математики (`13_RISKS.md`, R10). При этом ADR-0006
запрещает писать собственную ASR, но текстовый анализ — отдельная задача.

## Decision

Добавить собственный, не-нейросетевой модуль анализа текста `src/lessondigest/analytic/`:

- **TF-IDF** (`scikit-learn`) — ключевые термины урока;
- **TextRank** (`networkx` PageRank по графу предложений) — ключевые предложения
  (экстрактивный конспект);
- regex/эвристики — независимый детектор домашнего задания;
- модуль сравнения `compare.py` — метрики против дайджеста LLM (precision/recall/F1
  по терминам и предложениям, `grounded_ratio` по числам).

Модуль работает параллельно ветке LLM и не влияет на неё (см. `03_COMPONENTS.md` §12).
Артефакты: `transcripts/{run_id}.analytic.json` и `digests/{run_id}.analytic.md`.
Зависимости выделены в optional extra `analytic`.

## Consequences

+ Свой алгоритм и свои измеримые метрики — научная часть проекта
+ Экстрактивный конспект не может выдумать факт
+ Независимый детектор домашки и проверка «обоснованности» чисел дайджеста LLM
− Ещё зависимости (`scikit-learn`, `razdel`, `pymorphy3`, `networkx`)
− Качество зависит от лемматизации и шума ASR
− Extractive-предложения слабо пересекаются с пересказом LLM (низкий `sentences_f1`
  у «пересказных» дайджестов) — метрику нужно интерпретировать с оговоркой
