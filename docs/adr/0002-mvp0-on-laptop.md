# ADR-0002: MVP0 на ноутбуке (топология B)

- Status: Accepted
- Date: 2026-09-22

## Context

Варианты: всё на телефоне; всё на ноутбуке; гибрид Telegram; VPS.

Телефон + Termux + local LLM — высокий риск не уложиться в сроки.  
Нативное приложение — отдельная компетенция.

## Decision

MVP0: запись на телефоне диктофоном, обработка **Python CLI на ноутбуке**.  
Telegram — следующая версия (топология C).

## Consequences

+ Быстрый старт, простая отладка  
+ Достаточно для доказательства гипотезы  
− UX «перекинуть файл» неудобен — закрывается Version 1
