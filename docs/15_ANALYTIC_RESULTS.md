# 15 — Результаты: своя аналитика против GigaChat

Эксперимент: на трёх синтетических уроках (алгебра, физика, история) прогнан собственный
модуль аналитики (`docs/14_ANALYTIC.md`) и сравнён с дайджестом GigaChat.

## 1. Условия

- Транскрипты — реальный вывод `faster-whisper small` (не ручной текст).
- Дайджесты GigaChat: физика — `prompt v1.1`, алгебра/история — `prompt v1`.
- Наш метод: TF-IDF (top-12 терминов) + TextRank (top-7 предложений) + regex-детектор домашки.

| Урок | run_id | Аудио | Дайджест LLM |
|------|--------|-------|--------------|
| Алгебра | `20260928_algebra_lesson_3313fb` | 9.6 мин | v1 |
| Физика | `20260928_physics_v11_0037bf` | 8.5 мин | v1.1 |
| История | `20260928_history_lesson_4d9610` | 6.6 мин | v1 |

## 2. Метрики

`terms_*` — сравнение наших терминов с концепциями LLM. `sentences_*` — сравнение наших
предложений с `key_points` LLM (Jaccard ≥ 0.25). `*_grounded` — доля чисел из дайджеста,
которые реально есть в транскрипте (детектор выдуманных номеров).

## 3. Домашнее задание (наш детектор)

Все три домашки найдены с уверенностью `high` и совпали с LLM по номерам:

- Алгебра: «Повторяю, домашнее задание, параграф 12, номера 345, 346 и 347».
- Физика: «Домашнее задание, параграв 24, упражнение 18, задачи под номерами 2, 4 и 6».
- История: «Домашнее задание, параграф 16, вопросы с первого по пятой…».

Точность детектора домашки на этом наборе: **3/3**.

## 4. Выводы

1. **Термины**: `terms_recall ≈ 0.92` — почти каждая концепция GigaChat содержит слово,
   которое наш TF-IDF поднял в топ. `terms_precision ≈ 0.33` — в топе есть и «лишние»
   общеучебные слова, что объяснимо: у нас 12 терминов против 3–5 концепций LLM.
2. **Домашка**: наш regex-детектор находит домашку без LLM и корректно по номерам
   на всех трёх уроках; `homework_grounded` подтверждает, что номера не выдуманы.
3. **Предложения**: `sentences_f1` низкий у «пересказных» дайджестов (алгебра, история)
   и заметно выше у физики, где LLM формулировала тезисы близко к тексту. Это ожидаемо:
   наш метод **экстрактивный** (берёт фразы дословно), LLM — **абстрактивный** (пересказывает).

## 5. Ограничения

- `homework_grounded` по числам занижается, когда LLM пишет «5», а в транскрипте сказано
  «пятый» (история: 0.333 — в тексте словами, в дайджесте цифрами).
- Шум ASR («параграв», «Нью-Тона») напрямую влияет и на наш анализ, и на LLM (риск R13).
- Набор маленький (3 урока) — цифры индикативные, а не статистически значимые.

## 6. Что это даёт для защиты

- Есть **свой алгоритм** (TF-IDF + TextRank) и **свои метрики**, а не только вызов API.
- Есть честное сравнение с LLM и объяснение расхождений (extractive vs abstractive).
- Есть отдельный детектор домашки, не зависящий от модели.
